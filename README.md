# Hestle External v4
Учебный Telegram-бот по Python: курс из 108 тем, последовательное открытие уроков, XP, уровни, достижения, ежедневные задания и повторение.

## Запуск
1. Python 3.10+
2. Создай `.env` рядом с `bot.py`: `BOT_TOKEN=токен_от_BotFather`
3. `pip install -r requirements.txt`
4. `python bot.py`

`Start.jpg` должен находиться рядом с `bot.py`. Прогресс хранится в SQLite.

## Безопасность запуска кода
Код запускается в отдельном процессе с ограничением времени и памяти; импорты и доступ к файловой системе/сети не разрешены. Это ограниченный учебный исполнитель, не полноценная изолированная виртуальная машина. Не запускай бота от root и не используй его для недоверенных публичных запусков без отдельного контейнера/песочницы.

Не публикуй `.env`. При утечке отзови токен через @BotFather.
